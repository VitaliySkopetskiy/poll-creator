# Resume Project

This directory is intended to serve as a starting point for a separate repository where you can store your resume. It contains a placeholder JSON file that you can edit with your personal information.

To create a new standalone repository:
1. Copy the contents of this folder into a new git repository.
2. Add your resume details to `resume.json` using your preferred format.
3. Commit your changes and push the repository to your preferred git hosting service.

This folder is included in the `poll-creator` project only as an example structure. You may remove it from `poll-creator` after creating your separate repository.
