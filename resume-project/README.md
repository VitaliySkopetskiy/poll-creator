# Resume Project

This directory is provided as a template for a standalone repository containing your resume. The file `resume.json` currently holds your resume details in JSON format.

To create a new private repository:
1. Copy the contents of this folder into a new git repository.
2. Review or edit `resume.json` as needed.
3. Commit the result and push it to your preferred git hosting service.

You may remove this folder from the `poll-creator` project after you have created your separate repository.
